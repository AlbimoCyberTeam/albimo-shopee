# albimo-shopee

Marketplace multi vendor modern.

## Cara Upload ke GitHub Pages

1. Login GitHub
2. Buat repository baru
3. Upload semua file
4. Masuk ke Settings
5. Pilih Pages
6. Source -> Deploy from branch
7. Pilih main branch
8. Save

Website online dalam beberapa menit.

- index.html
- admin.html
- style.css

## Cara Membuat Admin
1. Register user biasa
2. Buka Firebase Realtime Database
3. Masuk ke:
users > UID_USER > role
4. Ubah value:
"user"
menjadi:
"admin"
